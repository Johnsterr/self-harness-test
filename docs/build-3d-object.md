Используй Blender MCP и создай в пустой сцене объект AI Core для веб-лендинга NEXUS.
Пути считай от корня проекта: узнай его через pwd и передавай в Blender абсолютные пути.

Требования:

- один центральный объект размером примерно 2 x 2 x 2 м;
- ядро из low-poly icosphere и трёх разомкнутых колец вокруг него;
- асимметрия небольшая, силуэт читается с первого взгляда;
- графитовый металл, электрический cyan и немного violet;
- мягкий key light, холодный rim light, тёмный world background;
- без текста, симуляций, внешних текстур и сторонних ассетов;
- не более 40 000 треугольников;
- применить transforms, поставить origin в центр;
- сохранить исходник в `assets/ai-core.blend`;
- экспортировать один файл `assets/ai-core.glb`.

Сначала коротко опиши план. Затем создай сцену, сделай viewport screenshot и проверь экспорт.
В конце верни: объекты, количество треугольников, путь к GLB и найденные ограничения.
